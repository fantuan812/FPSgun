# 核心区 v1 — AZ3 风格参考的原创工业场景

## 本批交付边界

本版定位为 **核心大厅 v1 + 基础外围**。外围立面、绿化和道路目前为功能与尺度搭配层级，不代表完整 AZ3 质量关卡或整张地图。

这是一套 **实际 Blender 场景**，不是生成图替代模型：中央分层反应器、两级检修环台、东西连接桥、两侧及后方廊道、双楼梯、底层控制台/状态屏、成组设备与管线、入口前场、后方真实出口及外侧服务道路。

参考三角洲 AZ3 的核工业视觉组织：深灰金属主体、灰白混凝土围护、克制的红色导向与黄色安全标线。造型及布局为原创重组，不是原地图精确复刻，不使用原游戏商标或提取资产。未尝试复制全图，也不将本批称为商业游戏最终美术精度。

前批大空间和原资产没有覆盖；本批只复用已交付 Batch04 中的泵、支架和货架网格，三项可用复用源已放入 `Reused/batch04_reuse.blend`。

## 打开与重建

源码 ZIP 是普通独立分包，不是分卷压缩。请将全部 Source 分包解压到同一个目录，保留 `NuclearPlant/Batch05_Core` 层级；无需旧批次文件。Exports 分包是独立的 GLB/FBX 导出，可按需要另行解压。

- 直接打开 `core_hall.blend`。全部几何与材质均为本地数据；不需要旧工作区或外链贴图。
- 需要 Blender 4.3 或更新兼容版本和 Python 3。
- 重建：`python rebuild.py`。固定执行七阶段：`build_core.py → postprocess_core.py → fix_clearance.py → refresh_reactor.py → material_finish.py → fix_loop.py → finish_scene.py`。从新几何开始，最后应用地基、屏幕位置及渲染设置修订。
- 请通过 `rebuild.py` 完整重建；部分增量修正脚本包含相对位移，并非幂等，不要在已完成场景上反复单独执行。
- 重建并渲染：`python rebuild.py --render`。
- 单独渲染：`blender -b --python-exit-code 1 --python render_core.py -- core_eye_front core_eye_side core_platform core_entry core_cutaway`。
- 独立新模块源码位于 `reactor/` 与 `props/`；独立正交三视图和尺寸记录也在那里。
- 重建输出会更新本目录中的 `core_hall.blend`，如需保存个人修改，请先复制目录。

## 配置不是输出伪装

`core_config.json` 是生成器实际读取的输入：

- `equipment_placements`：每条为 `[x, y, z, z轴角度]`，控制台、电柜、服务罐实例位置真实生效。
- `cameras`：镜头位置、朝向目标、焦距真实生效。
- `palette`、`source_palette_override`：基础色与复用泵色真实生效。
- `lighting`、`render`：灯光比例、世界亮度、渲染引擎/采样/输出尺寸。
- `structure_template` 为已审核的**约束拓扑模板**。当前不承诺任意改宽高就能自动重排全部管线/楼梯；修改任何结构数值会明确报错，而不是悄悄忽略或整体拉伸。要扩结构需先修改生成逻辑并重做净空验证。

`layout.json` 是生成结果摘要，不是配置输入。

## 关键尺度与可达边界

- 大厅内部约 40 × 36 m；屋顶约 20 m，主要屋架下缘 18 m。
- 主反应器本体半径约 4 m；含平台外廓 14.1 × 14.1 m，高约 14.11 m。
- 主环平台顶面 4.5 m，东西桥宽 3 m；两侧 gallery 宽 3 m。
- 两楼梯各 25 级、总升高 4.5 m、踏步高 0.18 m、踏深 0.28 m、宽 2.4 m。
- 两个内部地面镜头、入口镜头和平台镜头均位于实际支撑面上方约 1.65 m（1.650–1.655 m）；人物参照高 1.8 m。`camera_standing_check.json` 记录向下射线证据。
- 主环外圈为经检查的通行线；内圈存在设备、支架和低管件，不能声称整个平台任意位置都能通过。北南管道外侧的保守净宽约 1.259 m。
- 10 m 上环及安全笼梯属于检修表现。本项目未实现 UE 玩家攀爬/交互，不能用 Blender 静态检查冒充引擎可达性。
- 静态几何/射线净空检查不是真实 CMC/Mover 或多人交战验收。没有进行 UE 导入行走、导航、碰撞、LOD、性能预算或网络验证。

## 预览与参考严格区分

`renders/` 为实际 Blender Eevee 渲染；`core_cutaway` 只在该张展示时隐藏屋顶和近侧墙，完整 `.blend` 保留屋顶和围护。

`References/` 中的两张图是先行 AI 概念参考，用于模块/总览方向，不是已建场景截图，不是工程精确正投影。图的细节冲突由尺寸模板和实际模型统一。官方 AZ3 图仅用于研究，不作为本资产包的贴图或网格来源。
