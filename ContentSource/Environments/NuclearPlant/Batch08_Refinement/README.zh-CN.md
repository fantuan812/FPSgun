## 三个有限改进

### 01 — 连续服务边缘，而非随机填充空地

`B08_SERVICE_EDGE` 为4.0×1.05×0.39m组合件（底z=-0.05m、顶z=0.34m），含接地混凝土基座、独立检修盖板/螺钉/提手、浅排水槽与真实格栅、分段防撞缘和小面积反光件。连续服务带沿既有功能边缘接到建筑/围挡接口，不占主干道。`B08_SERVICE_EDGE_FLUSH` 保留历史资产标识，含义为同家族4.0×0.60m低台阶盖板派生，不是绝对零台阶齐平。v04按实际旧地面分段安装：相对高差10或27mm，设计内部分段顶面差最大18mm，对两端旧地面最大27mm；建模后33717个实际顶点/盖面/地界检查得到保守边缘最大27.500004mm，0处超过30mm。详见`QA/crossing_levels_v04.md`。受保护行走路线处使用它而不是高缘石。

这是可见几何高差，并非已经验证UE角色可通过。没有将格栅、线缆、低矮边缘或开放构架算作新实体防护。

### 02 — 墙装检修终端真正接到墙和地面

`B08_WALL_TERMINAL` 为1.57×0.5695×2.327m装配（含下延50mm的隐藏调平底层，地上顶z=2.277m），后安装面为局部Y=+0.16m，正面朝-Y。含背板/安装轨、锚栓、密封箱、门缝/铰链/锁、雨罩、插座、金属管路、接地线和落地接线盒。10个实例逐一按既有墙真实表面定位，不靠视觉估计悬挂。

### 03 — 原位货组精化，不堆新箱子

`B08_CARGO_DRESSING` 在原有12个货组上增加外覆布、褶皱、角部拼片、包边、鸡眼/绳带、贴合布面的连续绑带、扣件和箱体/托盘紧固件。保留原B07货组实体、不移动货物。新增层11037顶点/12178多边形，12个实例共享一个网格；独立资产Blend/GLB包括原B07基体与精化层，场景中只增加精化层，不重复原基体。

## 一键重建

验证环境为Linux、Blender 4.3.2和Python 3。需要PATH中的`blender`与`python3`；可选的前后对照拼版需要Pillow，重生成工程参考另需NumPy/Matplotlib。其他平台可能需要调整可执行命令名；尚未做跨平台验收。保留与`../Batch07_Refinement/site_refined.blend`的相对关系；累计包中的二进制若以ZIP运输，先按累计入口恢复资产。

```bash
python3 rebuild_all.py
# 可选：同一命令串行重建并出全部图
python3 rebuild_all.py --render
# 隔离目录复建、几何签名和GLB逐字节对比
python3 Scripts/check_rebuild.py
```

构建器会核对冻结输入及Batch07场景hash，不会静默改用其他源。重建不会修改Batch01–07源。不要同时运行多个Blender进程；场景QA、导出和EEVEE渲染均串行。渲染入口进一步按每张图片单独启动/退出Blender，避免长进程累积缓存；临时shader缓存放在可写系统临时目录。`python3 Scripts/render_serial_queue.py --resume`仅跳过源场景/脚本/相机/图片hash全匹配的已完成图。一次连续多图进程曾exit137，4张已完成图被保留，恢复记录在`QA/render_resource_recovery.json`，不将失败改记为成功。
