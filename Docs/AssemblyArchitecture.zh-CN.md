# 数据驱动装配系统：源码与验收边界

## 本批状态

新仓 FPSgun 的独立 Unreal Runtime 插件，不依赖或复制 AetherLab 工程。25 份定义、7 个装配示例由资产作者的最终视觉清单生成；模型是实际 Blender/GLB 交付，JSON 是作者数据，**不是已导入 uasset**。

**未编译、未运行规则测试、未运行 Unreal Engine、未完成 UE 集成。** 按执行顺序先完成代码与必要资产，再统一编译测试。本批只做源码阅读、JSON/脚本文本语法、接口与差异检查、上传字节核对；这些不表示行为验证。Blender限定的资产几何、GLB回读证据在资产目录，不推广为UE验收。

## 责任边界

- `Rules/AssemblyRules.h`：唯一装配规则。只认识稳定ID、标签、定义、实例与有界树，不知道枪名、UObject、Niagara、GAS、网络或磁盘
- `UFPSAssemblyDefinition`：只读 PrimaryDataAsset；槽位、兼容标签、依赖互斥、属性修正与软引用。修改同规则内容只改数据；新规则才扩展算法
- `UFPSAssemblyCatalog`：统一编译成规则定义，并检查定义与挂点。`CreateTransientCatalog` 从相同JSON创建临时同类型定义，不是另一套规则或持久资产
- `UFPSAssemblyComponent`：服务端候选与提交适配。既有库存/事务所有者负责身份、战斗中是否允许装配、角色拥有关系、幂等命令账本、磁盘写入及乐观锁；本插件不创建第二套经济存储或GAS权威
- `UFPSAssemblyVisuals`：只读组件树、异步网格加载、过期结果隔离。关闭或缺失展示不能改变规则/成本/伤害。没有开火逻辑、命中判定或真实武器机制

## 定义、实例与图

定义ID为小写ASCII `[a-z0-9._-]`，长度1–96；实例ID同约束，可用持久GUID的小写digits形式，不用物体显示名或数组索引。定义被所有实例共享；实例保存唯一ID、definition_id、耐久、品质、词条、绑定与锁定。所有部件各占一个实例，不堆叠；装配只改 `links(child,parent,slot)`，不会删除或复制库存部件。

当前独立插件不定义背包格子/商城/交易/弹药消耗。接入已有库存时，以其实例ID与已提交状态生成本DTO，库存所有者在同一事务中保存实例及links。禁止用 `RestoreCommitted` 或客户端本地实例凭空授予物品。

每child最多一个父亲；检查缺失引用、自环、环、深度、总实例数、每树容量、槽位容量、兼容、依赖与互斥。默认全库存256实例、每树64件、深度8；作者范围有硬上限。武器root不能当另一武器的配件。允许离体转接件保留其子瞄具，也允许不完整枪械。

`required` 是 **可使用条件**：`Validate`/编辑事务允许拆掉必需弹匣，`ValidateReady`才拒绝使用不完整武器。UI可继续显示和编辑。`requires_all` 每个标签必须由同一树其他节点提供；`excludes_any`禁止其他节点携带指定标签，均在结构校验中生效（离体子树也生效）。作者不得给可独立库存的部件填一个永远缺失的强依赖。

槽位 `accepts_any` 为精确标签任一匹配，不做自动父标签宽匹配。GameplayTags用于UE作者体验，编译为精确稳定字符串，避免子标签无意开放跨平台兼容。占位token作用域是父实例，可让不同槽位共享同一空间；带占位token的槽位capacity限定1。

## 事务与保存

1. 服务端现有命令入口验证拥有者和操作权限，提交 expected_revision 与一批 edits；公开插件没有接收任意owner字符串的客户端RPC
2. `Prepare`检查当前全状态，在副本上同时应用所有显式拆装，统一验证最终图；替换配件必须同批显式拆旧件和装新件
3. 无效、过期、锁定/异主绑定、占位冲突等错误不改变原状态或输出候选。受影响旧/新树任一节点的锁/绑定可阻止通过祖先移动绕过限制
4. `CommitCandidate`必须绑定到既有库存持久事务所有者，使用expected revision CAS，同步返回真实持久接受结果。拒绝后组件不更新状态、版本、展示通知或属性输出；不得在异步请求刚入队时返回true
5. 持久接受后才一次发布私有State和公开Presentation。组件有重入锁，不能在提交回调里递归换装/恢复

当前回调为同步边界，尚未接入任何具体游戏数据库。生产若使用异步库存协调器，应由该协调器负责整个pending/commit生命周期，再调用可信恢复接口；不要直接返回“成功”来伪装异步耐久。上层幂等账本/跨容器原子转移/重连会话授权不在本插件实现范围。

显式JSON codec版本1，revision用十进制字符串，避免2^53精度丢失。保存完整实例状态与links，不保存资源指针/定义。长度/数量/UTF转换/重复字段/整数/版本/引用全校验；解码在最后一步替换输出，失败保留已有状态。未知schema拒绝，没有静默迁移。定义ID或规则更改导致旧档无效时需显式迁移计划。

## 多人展示与隐私

私有State仅 `COND_OwnerOnly` 复制，不广播完整库存、品质、耐久、词条、绑定或锁定。服务端既有装备负责人调用 `SelectPresentation` 选择已提交的武器root，产生公开只读快照：Serial、SourceRevision、Weapon、选中树的part id/definition_id及links。所有相关客户端可接收该投影；隐藏武器时为空。

公开快照不接收玩家写入、不用于伤害/库存/统计权威。展示结构校验使用定义默认耐久的临时值，绝不把它当实际耐久展示。选择变化有独立Serial，即使库存revision相同也使旧异步回调失效。`BindPresentation`用于第三人称世界展示，`Bind`用于拥有者库存预览。复制/晚加入/网络延迟尚未实测。

## 属性、动画与Niagara

统计顺序为 `(root.base_stats + 所有节点add_stats之和) * 所有节点multiply_stats之积`。实例ID排序固定累积顺序，输出非有限值拒绝；不在旧值上叠加。当前数据中handling/stability仅为虚构游戏示例数值。品质/词条/耐久被保存，不凭空编造尚未定义的倍率。

宿主只从已提交、可用武器读取 `EvaluateStats`，按既有GAS白名单转换和撤销来源效果；不在视觉组件写ASC。动画和Niagara目前是软引用元数据，映射action key，尚未制作/播放完整开火、换弹、扳机、slide或握持动作。独立静态零件不等于动作系统已完成。

## 变换与资源

视觉来源为右手米制、+X前、+Z上；UE目标左手厘米制。采用Y反射S=diag(1,-1,1)：位置 `(100x,-100y,100z)`，旋转矩阵 `S R S`，四元数XYZW `(-x,y,-z,w)`。槽位是父网格原点到子网格入口原点的局部变换，逐父递推，非uniform/非正尺度拒绝。wisp侧灯有非identity源-90°X用例，不能只乘100。

网格导入必须使用同一基变换；GLB importer行为需实际核验，不可把数值公式当导入证据。源网格入口枢轴均0，已给出实际坐标；未触碰角色或PR13的握持基线。

当前 `mesh=null`、animation/effect映射为空是诚实占位：UE展示会报 `MissingMeshReference`，不会假装三把枪已在引擎显示。导入路线见 `AssemblyImport.zh-CN.md`。
