# Stitch Drone editable formal source

SVG files in source/ are hand-written semantic geometry from draw_stitch.py; palette/poses are code parameters. No embedded AI raster, trace or external asset. Original generated PNG identities in metadata/reference_provenance.json are historical references only and are not authoritative art.

Run python art_source/stitch_drone/export_and_measure.py from this project to regenerate local exports, compare fresh double-export bytes, measure alpha8 and produce draft metadata. Requires Python3/Pillow and Inkscape1.4. Runtime files are the matching exports copied to assets/enemies/stitch_drone.png (hover) and assets/actions/stitch_drone/stitch_drone_{channel,hurt,death}.png. Exact mappings/hashes in SOURCE_MAP.json. Do not copy measured metadata blindly over unrelated entries.

4 sheets x9/3x3/418 cells/1254 atlas. Action reference height336 from actual first frame; crop/padding/anchor measured. Logic/profile phase order unchanged. This is a partial asset migration, not whole-game SVG completion; legacy56 active PNG-authoritative assets remain. Source/pack/native independent acceptance pending. Full author preview is in external staging, not required at runtime.

When replaying an `export_command` recorded in `metadata/measured_assets.json` directly, use `art_source/stitch_drone` as the command working directory; its `source/` and `exports/` paths are relative to that directory.
