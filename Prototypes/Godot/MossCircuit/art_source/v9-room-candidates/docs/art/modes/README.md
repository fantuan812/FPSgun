# v9 房间清理状态徽记：候选素材交付

## 接入合同

只在 rooms 模式 HUD 目标区显示，不是场景出口、碰撞门或交互目标。锁定显示第 0 帧；全部敌人清理后，程序权威固定 0.6 秒安全过渡，按进度播放原始 0–8 帧，再停留第 8 帧。表现不决定结算，缺失素材必须使用几何 fallback，之后自动升级/商店/下一房。

manifest 在 `assets/modes/mode_art_manifest.json`。所有帧固定 440×280 canvas、中心 anchor，reference_width 400，显示参考宽 48。窗口按稳定机械中心定位，每列/每行共用位置；不逐帧按 alpha bbox 重新居中或缩放。原 PNG 未修改，AtlasTexture 切片为非破坏窗口。闭合横杠分开、支架打开、箭头形成、粒子离开及最后停留；颜色从琥珀到薄荷，轮廓同时改变。

## 视觉失败与使用限制（必须保留）

三次有界 imagegen 尝试均仍有可见环境晕。第一张动作最完整，保留作为候选动画源；一次编辑未去晕，最后简化重新生成仍带晕且网格偏移，因此没有继续尝试。**交付 PNG 不是干净 cutout，不是视觉验收通过的生产图。默认采用程序几何 fallback。** 若采用仅 HUD 的 alpha-cutoff 材质，须明示其是运行时抑制，不修改原 PNG，且经过真实 GUI 对浅/深底及 48px 显示验证后才能改为默认。没有执行 GUI 整合验收。

alpha>8 的非空、边距及帧差异验证只说明有效实体切片未越界，不能证明低 alpha 外围透明干净。`validation.json` 明确 visual_clean_cutout=false。9 帧字节不同不等于9种语义动作；最后两帧都是保持清理完成状态。

## 来源和色彩

原创 Moss Circuit 状态美术，由 OpenAI imagegen 生成。完整请求与源路径在 prompts.json，三份未经像素编辑的原始 PNG 保存在 sources。绿铁/深炭机械外壳、琥珀锁定条、浅薄荷清理箭头延续 v8；生成结果不保证严格四色或低分辨率像素量化。未导入第三方人物或引擎源码。没有 Python 编辑、阈值抠图、重绘或缩放 PNG；Python 仅读取像素测量并写 JSON。

v8 资源未改，空手主角/独立武器/特效分层不变。没有新增地图、探索门或地牢资源承诺。
