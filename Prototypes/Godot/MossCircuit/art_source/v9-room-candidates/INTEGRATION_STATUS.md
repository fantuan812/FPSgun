# Not a runtime asset

This is the bounded three-attempt producer handoff, retained unchanged for provenance. Nested `assets/` and manifest `res://assets/modes/` paths refer to the producer's proposed asset layout, not this game's active resource root. No runtime script loads this manifest or its PNG.

All three sources failed clean-cutout visual review. `ui/mode_status.gd` therefore draws the default pixel HUD indicator procedurally. It does not emulate a physical doorway. No alpha-cutoff shader or GUI acceptance is claimed. The fixed 0.6-second transition is gameplay policy, not driven by sprite completion.
