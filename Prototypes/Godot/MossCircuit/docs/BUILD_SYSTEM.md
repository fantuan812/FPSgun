# 构筑与经济（v2，v3沿用）

v3新增中场Boss协议及终场奖杯，见 [敌人与Boss](ENEMIES_AND_BOSSES.md)。第3/6波需满足Boss击杀和波时间双条件，其他商店规则沿用。

本轮提供可测试的**局内构筑闭环**，不是已经完成平衡的商业成品。无局外存档、联网或商店付费。

## 流程
战斗拾取绿色经验/废料 → 经验升级三选一 → 波末自动回收残留拾取物、回血、发放废料 → 免费波末升级 → 商店买/刷新/出售/替换 → 下一波。第六波结束直接胜利。

- 开局 35 废料、铆钉枪；4 武器槽，8 种道具槽，同种道具可堆叠到自身上限。
- 每次刷新花 5，四个唯一货品；已买货品售罄。商店 RNG 与敌人/升级 RNG 分离。
- 满武器槽可以选择替换；**旧武器直接销毁，无返款**，可先出售再购买。不能卖掉最后一把武器。
- 出售单件返还原价 50%，回收器最高提升至 80%，向下取整；出售回收器本身采用出售前的回收率。刷新不退款。
- 拾取幸运加成允许小数，累计小数余额再发整数，避免每次向下取整使加成无效。
- 显示的稀有度是目录分类，本轮货架等概率抽取，**不是稀有度加权掉落**。

## 行为不同的四种武器
| ID | 行为 |
|---|---|
| rivet_gun | 单发自动瞄准最近目标 |
| scrap_shotgun | 5 弹扇形散射，较短射程，弹丸袋可加弹 |
| rail_lance | 较慢高伤长程弹，可穿透 3 个额外目标 |
| orbit_saw | 周期近身圆形锯扫，同次对半径内每敌人只伤害一次；不是常驻物理刚体轨道武器 |

武器各自计时，允许多把同类。弹丸创建时固化伤害、穿透和寿命，后续商店变更不会追溯改变旧弹丸。商店前会清场。

## 三个明确的协同构筑
标签累计：每把武器计 1、道具每层计 1。达到 3 激活。

1. **电磁**：电磁枪 + 电容×2，激活 ARC GRID，额外 +20% 电磁伤害。
2. **锯扫**：环绕锯 + 齿轮×2，激活 SAW RIG，额外 +20% 近战伤害；护甲/苔藓适合近身生存。
3. **散弹**：散弹枪 + 弹丸袋×2，激活 SCATTER RIG，额外 +1 弹丸，共 8 弹。风扇提高攻击频率。

以上是规则可组合、攻击差异及阈值测试通过的路径，**不是已真人证明的通关最优流派**。每件道具名称、价格、稀有度、描述、效果、标签和层数上限的唯一源是 `data/catalog.json`；UI 不计算伤害或扣钱。

## 派生与交易边界
- `build` 保存购买层数、武器 ID、升级次数、整数钱和小数余额；`Rules.derive` 每次从基础值重新计算，避免重复刷新 UI 叠加属性或出售留下残余加成。
- 最大生命提高不自动回血，只有升级 health 和波末治疗明确回血；卖护甲时当前 HP clamp 到新上限。
- 全局伤害：基础伤害 × (1+所有全局伤害加成)；电磁/近战再乘 (1+对应类型加成)。攻速：基础间隔 / (1+haste)，下限 .09 秒。
- 上下文 generation 在新 run、每次交易/刷新/离店变化；旧按钮重复回调不能重复扣钱/买货。
- 买入先检查 ID、钱、上限、槽位再修改；失败不扣钱。出售和购买限定 shop 状态。
- 配置入口拒绝非 JSON 对象；catalog 校验重复 ID、必需字段、已知行为/效果、数值类型/正负/有限性、整数价格/层数和列表类型。balance 仍应遵守 README 的数值边界，非任意外部配置解析器。

## 复现
相同 seed 与相同商店操作序列获得相同货架。刷新次数、升级决策、战斗输入改变结果；不是跨版本或跨帧率完整确定性回放。
