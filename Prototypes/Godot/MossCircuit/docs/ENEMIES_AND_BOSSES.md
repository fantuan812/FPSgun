# 敌人与 Boss：v3

本轮扩展局内敌人/Boss闭环，不表示存档、音频、剧情或商业发布流程全部完成。行为唯一配置在 `data/encounters.json`，状态机在 `scripts/enemy_ai.gd`，伤害和场景状态由 main 消费事件。手册可从标题或暂停界面打开。

## 五种普通敌人

| 敌人 | 真正的行为差异 | 应对 |
|---|---|---|
| Scrap Crawler / 追踪甲虫 | 直接朝玩家移动，接触伤害 | 保持距离 |
| Amber Ram / 琥珀犀牛机 | 锁定朝向→0.65秒线形预警→直线冲锋→0.8秒恢复 | 横移离开预警路线；准备和恢复期接触安全 |
| Violet Spitter / 炮口虫 | 试图保持230像素距离，准备后发射有速度的瞄准弹 | 看到预警后横移；弹丸粉红色 |
| Knifeleg Flanker / 刀足蛛 | 随时间交替侧向切入，非直线追击 | 注意侧面，不只后退 |
| Moss Broodkeeper / 巢母 | 近距离退避，准备后召唤追踪甲虫；每母体最多3只存活子体 | 优先处理母体或清小怪 |

子体也计入90敌人全局上限。母体死后已有子体保留，但不能再召唤。现有敌弹在发射者死亡后清除，给击杀一个明确的安全回报。

## 六波组合
1. 追踪甲虫。
2. 甲虫、冲锋、远程混合。
3. 甲虫、侧袭 + 中场废铁守卫。
4. 冲锋、远程、侧袭。
5. 远程、侧袭、巢母。
6. 甲虫、远程、巢母 + 终场孢子反应堆。

普通波到时清场。Boss波达到30秒只满足时间条件，**仍必须击杀Boss**，不会自动删Boss跳关；Boss先死则剩余时间仍继续。战斗中的经验升级会冻结敌人、预警和弹丸。

## 两个 Boss

### Scrap Warden / 废铁守卫（波3）
- 第一阶段交替锁向冲锋与锁定玩家当时位置的地面爆破。
- 每次0.85秒预警，冲锋线/爆破圈画在世界空间；爆破只在圈预警结束的一次事件中造成伤害。
- HP≤50%进入第二阶段：移动倍率1.25，招式冷却缩短为原值/1.2；仍保留同长预警，不取消反应窗。
- 预警及恢复期不造成接触伤害。爆破标记不会在最后一刻追踪玩家。
- 首次击杀获得 **WARDEN PROTOCOL**：最大生命+25、全局伤害加成+10%、恢复25HP、50废料。这是本局唯一协议，不占可售卖道具槽，不可重复领取。

### Spore Reactor / 孢子反应堆（波6）
- 第一阶段保持距离，预警后释放8向慢速环弹；弹速145，方向留有间隙。
- HP≤50%第二阶段：12向环弹，每三次招式中的一次改为召唤两子体，同样受3子体上限限制。
- 每次0.85秒圆环预警。玩家可走弹幕间隙，或利用Space冲刺短暂无敌。
- 首杀获得100废料与结算奖杯 **REACTOR CROWN**。奖杯是最终战利品，不虚称其还有后续战斗属性用途。

## 伤害与状态边界
- EnemyAI只发shot/ring/blast/summon事件；main统一消费、产生弹丸和伤害，不能预警还没结束就提前打中。
- 死亡敌人不进入AI；死亡发射者的弹丸在碰撞前滤除。敌/我弹丸寿命到期立即移除，末帧只移动有效寿命部分。
- 玩家统一 `_hurt` 检查playing、受击冷却和冲刺无敌；暂停/商店/手册无伤害。
- 首先发生玩家死亡会锁定dead；迟到Boss击杀/结波不能把死亡覆盖成胜利，也不能授奖。
- Boss奖励校验死亡、Boss标志、playing和已领奖字典。新run清空协议、奖杯、弹丸、Boss阶段标志。
- 视觉反馈是代码几何预警与弹丸，角色采用生成九帧移动/脉动；没有把静态立绘或预警线称作九帧攻击动画。

## 验证边界
本轮以headless状态/碰撞/时序/资源/UI结构测试验证。尚无真实窗口实玩或Windows验收，因此不宣称预警对比度、Boss难度或所有构筑通关率已验证。
