# v8：角色身体与可换装武器分离

## 修正的问题

v7 的 `hero_attack` 把一把手枪和枪火烘焙进角色。六种武器虽有不同玩法，但没有对应的世界武器装配，不能把那张图当通用武器动作。本版更换为**空手九帧身体动作 + 独立世界武器层 + 事件枪口特效**。实查旧 walk/idle/hurt/death/dash 都为空手，因此保留，不重复生成。

原有 v7 图片与记录保留作历史资料；运行时 `actor_actions.json.hero_modular_manifest` 覆盖攻击资源。新资源缺失时不偷偷回退到旧烘焙枪图。世界武器用独立生成的 world sprites，不拿背包图标冒充完成。

## 四槽到底如何装配

- 槽 0 是主手，跟随每帧 grip。主手开火/投掷才驱动身体发力动作；环绕锯不播放持枪射击身体动作。
- 槽 1、2、3 是明确的辅助悬挂装置，跟随身体挂点及各自偏移，不宣称角色有四只手。槽 1、2 在角色后层，槽 0、3 在前层，预警仍在全部装备之上。
- 重复武器也各有独立节点、后坐状态与槽身份，不能以 weapon ID 当唯一实例。
- 角色逐帧挂点在 `data/hero_sockets.json` 和 clean action 的 frame.grip；使用当前画布、offset、scale、rotation、镜像变换。它是 Sprite2D/逐帧数据装配，**不是骨骼动画或自动 IK**。旧动作挂点是手工标注近似值，未经过真实窗口手感/逐像素遮挡验收。
- 枪、霰弹、轨道炮各用不同世界外观，朝目标旋转；左瞄准通过变换矩阵的负 Y 缩放保持枪体朝向，握点和枪口同一矩阵。
- 环绕锯显示旋转锯片与既有范围提示，但玩法仍是**定时整圆扫击**，并不按锯片瞬时角度逐点碰撞。
- 回旋盘实体图严格位于真实 `bullet.pos`。某槽有在场的盘时，该槽架上图隐藏；另一同种槽不受影响。原玩法允许多盘同时在场，并未为图像同步偷偷限制射速。
- 迫击炮独立炮身后坐，发射点到已锁定爆点有程序化像素弹道；这条视觉抛物线**不增加碰撞判定**，伤害仍由原 0.6 秒定时爆炸完成。

## 枪口、子弹和射程：有意的 v8 几何调整

不是只挪火光、让子弹仍从 `player+aim*16` 冒出。`WeaponRig.muzzle_pose` 纯函数接受挂点、目标、世界武器 grip/muzzle/尺寸数据，返回同一份 mount、muzzle、方向、角度和缩放。武器节点、当次发射和枪口特效共用此结果。独立 VFX 图层沿用像素网格 round(muzzle)，只存在小于一个显示像素的网格量化，不另算发射位置。

1. 当次发射用未后坐的静态 pose，并在本 tick 保持；之后后坐仅表现，不能改变已经发射的弹体或下一次逻辑起点。
2. 散弹同一炮口发出各个扇形方向，每颗弹各自 hit 集合。极近目标距离小于武器横向枪口偏移时，精确枪管交点不存在，使用受限 asin 姿态和首段碰撞兜底，不宣称这一特殊情况下枪管精确指向目标。四槽分别从自己的挂点瞄准，仍选择原来按玩家距离判定的最近存活目标。
3. 正常飞行距离裁到以**玩家发射时位置为圆心、既有 reach 为半径**的正向交点，避免辅助位平移暗中增加世界射程。零向量、圆外起点、零射程不产生 NaN 或额外入圆飞行。
4. 为避免枪口已经越过贴脸敌人，弹体首步先处理一次挂点→枪口的短段。短段与后续飞行段复用相同的伤害、穿透、命中事件和 hit 集合，按敌人碰撞圆首入段的距离排序，不额外白送一次命中。同距离按敌人 ID 稳定排序。
5. 回旋盘仍是出航和返航各自一次命中集合，首段属于出航，不当成回血用的返航命中。
6. arena 仍只有玩家移动边界，**没有新增墙体**。挂载武器/弹道可能越过 arena 边沿，这是现有场景约束而非假碰撞墙。

因此：伤害数值、冷却、RNG 规则及目标门槛保留；**实际命中可能因发射起点、近身短段和范围裁切改变**，不声称判定与旧版逐字节相同。旧的数组顺序也不再决定穿透先后。

## 生命周期

暂停/背包/商店/升级不推进后坐与武器视觉时钟。换装、出售、同 ID 替换、标题、死亡、重开清掉旧节点和悬挂盘隐藏状态。换装时取消旧的在场弹体与待爆弹，防止槽位重排产生幽灵所有权；正常交易本就发生于已清战场的波间商店。不改道具/升级所触发的同装备重算。

装配代码不抽取 gameplay RNG；没有等待 PNG/动画完成才结算伤害的回调。
