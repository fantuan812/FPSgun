## Rejected findings and honest test corrections

- **Real r1 endpoint defect:** a mathematically exact second boundary was missed by a tiny floating residual. Reproduced with Rooms start(860,320), RIGHT, speed470, budget1260 and advances100/470 then960/470. Fixed by the reviewed EPS reach comparison and consuming only actual remaining budget; endpoint damage then expiry still prevents free reflection. Rejected helper/test/log retained.
- **Real pre-r3 coincident aim defect:** actual mounted fire used a synthetic far-right point and tilted slightly. Independent actual-fire checks reproduced32 failures; the fixed-direction path now gives exact RIGHT for shot and mount across four slots/two initial facings/both modes. Old noncoincident solver preserved.
- **Oracle tolerance correction:** the r2 endpoint tolerance intentionally snaps within EPS, so an earlier tiny-step expectation could already have reflected. The revised three0.00005-travel steps test cumulative rather than per-frame progress. Original failed expectation/log retained; this was not hidden as a production regression.
- **Fixture-only overlap:** v1 disabled gameplay processing but measured HUD geometry only once, producing test-caption/objective overlap. V2 repeats presentation-only HUD measurement and adds Q quit; no production UI patch was made. Original fixture/capture retained; fixture hashes and chronology are explicit.
- **Invocation-only startup failure:** one seed-search attempt set HOME but omitted inherited XDG overrides and failed before running the script. Retried only with all isolated writable HOME/XDG roots. The private raw log hash and exact classification are retained; no game bug claim.
- New-entry validation guards were independently tested with malformed values after the author found unsafe type comparisons. All reviewed valid catalog behavior remains unchanged.
