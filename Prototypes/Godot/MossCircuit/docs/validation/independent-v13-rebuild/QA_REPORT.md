## Reproduction

Set writable `XDG_DATA_HOME`, `XDG_CONFIG_HOME`, and `XDG_CACHE_HOME`. Run `godot --headless --path PROJECT --editor --import --quit`, then `python3 run_suite.py PROJECT OUTPUT`. Run `godot --headless --path PROJECT --script independent_authority_trace.gd -- TRACE.json` separately for baseline and candidate, then `python3 compare_traces.py BASELINE.json CANDIDATE.json`. The trace script disables only the four newly supplied enemy reactions, not hero socket animation resources. Pixel verification takes the art handoff directory containing both manifests and four PNGs. Delivery single-ZIP CRC/SHA/manifest checking is a subsequent gate; it is not claimed complete in this report. No split archives are requested for this delivery, so split-union checking is not applicable.
