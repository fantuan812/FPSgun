# MossCircuit v9：模式化垂直切片策划合同

状态：2026-10-22；v8实读基线，v9范围与程序已确认；非发布说明，线上仍为v6，v8未上传。所有平衡判断均为设计假设，不是真人实玩结论。

## 一手参考及设计取舍

Blobfish 的[《Brotato》Steam官方产品页](https://store.steampowered.com/app/1942280/Brotato/)（2026-10-22核对）说明默认自动攻击、短流程、20–90秒的波次和材料驱动的经验/波间商店。这里仅借鉴“移动生存→收益→取舍构筑→下一挑战”的节奏：战斗验证决策，商店改变下轮行为。MossCircuit保留原创苔藓电路/废料回收题材与自身4武器槽、8道具类规则；不复制角色、素材、道具清单、概率或波数。官方页并不足以证明具体商店权重公式，因此不把社区公式称为官方事实。

## 已存在的真实基础

实读 `scripts/main.gd`, `rules.gd`职责入口、`data/catalog.json`, `balance.json`, `encounters.json`以及BUILD_SYSTEM/SHOP_AFFINITY/ACTION_COVERAGE。

- 目录真实为6武器、26道具、3标签协同、8机制配对；不是新加v9内容。共享Rules承担派生/交易；Effects承担事件机制且阻止二次伤害递归。
- 六波，每波基础30秒；第3/6波Boss击杀还须满足时间。局内经验三选一、波间免费升级、商店购买/出售/替换、刷新偏向与独立商店RNG存在。
- 冷却/弹丸/余烬/护盾/计数/奖励均存在瞬态；暂停、背包、升级、商店冻结。旧generation拒绝重复交易/升级。
- 五普通敌人、两Boss，分层角色动作/武器/VFX，主角动作有九帧来源；普通敌人受击/死亡多为程序化，不冒称全动作原画。
- 现有地面是种子视觉，不是可导航地牢；main仍直接引用waves、encounters.waves、wave_time。已有“规则模块”不等于已完成“模式插件”。
- 尚缺真正GUI/手感/平衡验收、房间图/障碍连通/探索、音效音乐、局外存档；本轮不得用headless报告替代。

## 本轮范围（程序合同已确认，实现待验）

必须保留原六波Survival。新增一个明确标记为Prototype的极小房间清敌模式作为架构压力测试：3个固定遭遇房间，共享现有角色/武器/道具/奖励界面，前两房结算分别升级与商店，第三间清场胜利。非完整地牢：不承诺随机房间图、门碰撞、钥匙、迷雾、探索资源或局外成长。模式ID为arena/rooms；不得扩大系统范围。

## 所有权合同

|共享运行层|模式专属层|
|---|---|
|角色输入/移动/受伤/冲刺、武器计时和伤害、效果事件、build/Rules派生、拾取、升级与商店交易、RNG分流、动画/音画|阶段列表/生成计划、何时可结算、是否需Boss、倒计时或清场目标、阶段奖励参数、是否开商店、下一阶段/胜利、目标HUD文本|

模式只返回描述/决策，不持有玩家/怪物Node，不直接扣钱/改build/调用UI。共享层消费模式定义：一次结算门、原子奖励、清理瞬态、统一呈现。禁止把第二套武器/商店/效果脚本复制进地牢目录。

阶段完成必须同时满足：模式目标达成且state=playing且本阶段未结算。清场模式还必须确认本房间生成计划耗尽（不能第一帧空数组就胜利）；召唤出的活敌计入清场。Survival时间未到时即使Boss早死不能结算；到时Boss仍活不能结算。

## 状态与重置

- 标题选择模式；游戏中不得静默带着构筑切模式。退标题→选模式→新开局彻底重置本局；retry保留选定模式与seed、重建干净run；new seed只换seed不换模式。
- 共享可保留：会话显示设置。必须重置：武器/道具/升级/金币小数余额、HP/经验/等级/击杀、所有战斗对象与计时、Boss奖励去重、阶段生成计数、房间目标/出口状态、死亡尾播、商店货架/待购买、升级choices/待选择、effect epoch/计数。
- shop_generation/choice_generation不可回到旧值；跨run旧UI回调必须失效。新模式开局后再到相同shop/upgrade状态，旧按钮也不得生效。
- 阶段内暂停/背包/设置冻结阶段时钟、生成计划、武器/动画/特效；阶段间保留build、已得金币、合法局内成长，仅按明确规则恢复HP；阶段奖励最多一次。
- 死亡从任何活动战斗立即停止玩法；九帧尾播仅表现。死亡期间退标题/重开不能让旧结果浮层覆盖新run。

## 一批美术需求（与程序确认后生效）

单套“阶段出口/清场信标”九帧素材，原型无物理门则只作状态徽记，不诱导玩家必须走过去。原创苔藓铜线/三叶电路外形，非石门、宝箱或Brotato资产。锁定=闭合断路+琥珀，解锁=开合导通+薄荷，形状与颜色双通道。沿用现有主角动作、空手身体/独立武器/VFX分层；不新增大批角色。

合同建议：透明RGBA，3×3顺序0–8、每cell64×64、总192×192，固定中心anchor(32,32)，像素nearest；命名 `moss_exit_beacon_9f.png`，独立manifest记录cell/anchor/alpha_bounds/release_frame及原始文件。外圈非碰撞、仅装饰，不遮蔽真实危险圈/玩家脚底；禁止背景烘焙/闪白满屏。调色沿既有暗蓝底、苔绿、薄荷、琥珀，轮廓保持暗色。若程序只需HUD徽记或已有适配合同，以程序确认尺寸为准，不为此引入世界交互系统。
