# v6 九帧像素动画特效

本版只增加表现层，不改武器/道具/Boss伤害、触发条件、商店权重或随机序列。`scripts/vfx_layer.gd` 不持有游戏对象，不发伤害信号，不调用随机数；缺素材或池满不会取消逻辑结果。

## 六主题与真实接线

| 主题 | 触发位置 | FPS / 时长 |
|---|---|---|
| muzzle_flash | 武器确实发射且目标在射程内时，枪口朝向瞄准方向；不是持续常亮 | 30 / 0.30秒 |
| hit_spark | 主武器实际命中、链电实际命中及玩家实际扣血时 | 27 / 1/3秒 |
| explosion | 迫击炮延迟结束、地雷实际爆炸、相位电容释放、敌方爆圈释放时 | 18 / 0.50秒 |
| chain_arc | 链电实际对次级目标结算时，两端连接主命中点与次级目标 | 24 / 0.375秒 |
| shield_impact | 镜盾实际消耗并格挡时，不在普通受伤时冒充护盾 | 18 / 0.50秒 |
| dash_trail | 实际冲刺开始事件，朝向移动方向 | 24 / 0.375秒 |

每个主题使用一张真实生成的3×3九帧PNG，顺序为从左到右、从上到下；应有轮廓/火花/散布/消退的帧间变化，不是九张等比例缩放静图。原PNG保持不改，`assets/vfx/vfx_manifest.json`记录各帧区域与固定锚点。美术实际检查和生成记录见 `docs/art/vfx/`。

## 时间与逻辑隔离

- 既有结果事件决定伤害；同一事件只请求播放。逻辑不会等到图片某一帧才结算。
- 主循环先推进旧特效，再运行战斗，因此本帧新事件从**第0帧**显示。释放特效首帧与伤害结果同一战斗tick；后续散逸不重复造成伤害。
- `data/vfx.json`配置帧率、9帧时长、启动延迟（本批均0）、混合方式（本批均普通alpha mix）和默认画布尺寸。时长须等于9/FPS，非法配置不启用该效果。
- Sprite2D纹理由表现层按时间选帧，不创建物理体；逐帧复用固定画布/锚点，**不会按每一帧alpha包围盒重新居中或缩放**，避免火花抖动。
- 最近邻过滤、纹理区域clip、像素位置取整。定向枪口、链电和冲刺允许旋转；旋转后的像素边缘仍受离散栅格限制，不声称任意角度都保持美术级像素网格。
- 同步seed与操作下，装饰不改变敌潮、掉落、商店RNG；没有额外随机闪光调用。

## 范围与预警

`telegraph_layer.gd`在z=20绘制精确危险线/圈，始终高于z=12的装饰动画，并带深色外描边。冲锋预警宽度和长度、Boss爆圈、迫击炮固定落点等仍由原逻辑给出，不用模糊火焰代替判定范围。

带半径的爆炸纹理整体方形缩放到对应圆内部，动画不夸大覆盖区；准确圆形边界仍保留。链电按素材manifest的水平端点映射两目标，仅表示已发生的链击，不能作为碰撞体。

## 池、冻结、清理与失败模式

- 活跃特效上限96；满时回收最旧的一个再复用。Sprite2D数量有界，不因连锁叠加无限增长。
- 播放完成隐藏并清纹理，回到复用池；没有持续循环或残留计时器。
- 暂停/背包/升级不推进特效时间。重开、标题、结波、死亡/胜利清活跃实例和预警；池保留供复用，但旧generation实例不会回来。
- 未找到某张PNG时，仅显示明确的几何线/圈fallback；`fallback_count`可诊断。fallback不能被称为完成的九帧动画，最终交付要求六主题均载入真实图像。
- 原几何命中闪光、危险区和部分轨迹保留用于清晰判读；本版不声称全部游戏表现都已经逐帧化。

## 验证边界

`tests/test_vfx.gd`检查六类时间轴、0–8帧、回收、池上限、配置、像素取整、实际战斗hook、暂停重开、随机数状态和预警层级。最终必须不带`--allow-pending`运行；该选项只用于素材未到时明确标注的开发检查。

独立验收复测旧全部玩法回归及真实纹理、链电两端和满池/关闭视效后的伤害与RNG一致。GUI受既有环境权限限制，未重试绕过：headless结构与资源通过不代表已经窗口实玩、视觉对比度/手感/性能或Windows验收。图片预览也不是运行截图。
