# v5 构筑刷新倾向与新装备

## 抽样规则：提高机会，不是保底

刷新从所有尚未达到叠加上限的装备组成池子，顺序抽取最多4个不同ID。每选一个便从当轮池移除，**无放回**；没有隐藏必出、失败补偿或暗改seed。

每候选权重由 `data/catalog.json/shop_weighting` 定义：

`min(6, 1 + min(2, 0.35 × 已拥有装备对候选的共享tag计数) + 缺配对伙伴时2.5 + 已有同ID武器时0.5)`

- 基础权重1始终为正，未相关装备仍可能出现；武器和道具每个实际拷贝都计入tag计数，但tag加成最多2。
- `affinity_links` 登记双向配对：只拥有其中一方时，缺的另一方增加权重；不是只按名称猜测。
- 当前金币不足不排除高价装备；武器槽满不排除可替换的新武器。只排除已达自身叠加上限的ID。道具种类槽满时仍可能看到暂不可买的新道具，可先出售腾槽。
- 同ID武器允许多槽，最多4件，总武器槽4。替换会销毁旧武器且不退款。已拥有4件相同武器时，该ID不再出现在刷新池。
- UI的货架倍率是**抽到时相对基础权重**，不是概率；每槽概率受当前剩余池影响。出售后偏好快照立即更新，但既有货架不偷偷改变；下一次刷新使用新构筑。
- 商店RNG独立。同版本、同seed、相同购买/出售/刷新顺序可复现货架序列。帧时间和战斗输入不同不保证整个游戏逐帧重放。
- 刷新仍使用原子扣币与generation防旧回调。价格不会因偏好改变。

## 新武器（共6种）

| ID | 行为 | 联动 |
|---|---|---|
| return_disc | 飞盘先出航后追踪返回玩家；去程和回程各对每个目标最多命中一次，阶段跨帧时分段碰撞。最多存活2.5秒 | return_spool仅回程主命中回血 |
| shock_mortar | 锁定发射时敌人位置，蓝色85px圈预警0.6秒后爆炸；目标可移出，不追踪改落点 | blast_fuse在落点留下灼烧区 |

## 新独特道具（共26件）

六件均上限1，消耗一个道具种类槽，不是重复加属性：

| ID | 触发与真实行为 | 边界 |
|---|---|---|
| return_spool | 回航飞盘主命中回复1HP | 全部飞盘共享0.6秒ICD；去程及二次伤害无效 |
| blast_fuse | 迫击炮爆炸后留下半径60、1.4秒余烬区；每0.35秒6伤 | 最多3区，新的替换最旧；出售立即清区 |
| echo_chamber | 每5次主武器命中，对第五个目标附加12伤 | 目标已死则没有额外伤害；proc不计数、不递归 |
| gravity_anchor | 地雷爆炸后把150px内存活敌人向爆心拉60px | 不复活死敌、不额外造成伤害；需scrap_mine产生地雷 |
| medic_seed | 每累计30实际HP损失产生8HP医疗球，余数保留 | 护盾格挡不算损失；最多8球，超出替换最旧；医疗球不触发地雷/能量充能 |
| phase_capacitor | 冲刺存1层电荷，下一次主命中消耗并在命中点95px范围造成12伤 | 重复冲刺不叠加；二次伤害不触发；与pulse_boots同一冲刺分别推敌和蓄能，无隐藏倍率 |

主伤害发出 `hit`，新道具只产生命令，不递归发送命中事件。迫击炮一次爆炸可主命中多个目标，因此可累计多个回声计数；其余烬不算主命中。飞盘两个航段各一次命中也分别计数。旧链电/击杀/护盾等机制保持。

暂停、背包和升级冻结飞盘/迫击炮计时、计数、余烬和电荷，仅使旧事件epoch失效；结波/重开/结算清瞬态，卸下道具清其计数或生成区。医疗球波末自动回收治疗，不给经验或金币。Boss照常受合法伤害，死亡奖励走原有幂等门。

## 实际验证边界

`tests/test_expansion.gd` 覆盖565项精确规则、同seed顺序抽样、正权重/上限、非法配置、6新道具、真实飞盘和迫击炮闭环。独立测试另检查4000固定seed首槽样本：中性构筑出现回收线轴136次，持飞盘431次。该结果仅是此固定样本的首槽经验频率，**不是所有seed的保证或四槽出现概率**。见最终验证日志。

所有数值为原型初值；尚未真人平衡或窗口渲染验收。生成图标用于商店/构筑卡；战斗轨迹、预警与地带由代码绘制，不伪称每种武器已有九帧攻击动作。
