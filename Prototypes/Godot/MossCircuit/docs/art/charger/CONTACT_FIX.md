# 接地点修订 · 2026-10-22

初版 death 第0/1帧是应接地的中性/屈膝姿态，却出现非有意的11/7源像素浮空。遵照本轮人工复核，唯一修订为这两帧的 AtlasTexture region.y：70→59、70→63。固定418×320裁片、anchor y300、reference_height199、原PNG字节及其余25帧全部不变。

这是两个作者指定接地关键帧的显式平移，不是全帧按bbox自动居中/缩放。新alpha>8实体底均为300。读像素比较新旧窗口，alpha>8有效实体像素数分别39671/36255，前后完全相等，确认可见身体未裁掉。新窗口仍在第一行内且不跨列，不会引入邻格实体，最小有效边距检验通过。透明区仍有alpha1–8细碎低透明像素：第0帧总非零像素49306→49380，第1帧46377→46349；因此不声称所有非零像素都相同，但原始PNG始终未改。

旧manifest与validation保存在history，README中的初版误差记录保留为历史事实，当前状态以本修订为准。该改动消除已知头两帧接地浮空；不代表所有生成姿态逐像素完美，也不代表实际GUI整合验收通过。程序必须重新复制metadata并重新检验/封包，旧包不能沿用。
