# Charger 专属九帧动作 · v10

本批仅增加 charger_charge、charger_hurt、charger_death 三套原画，共27帧。不重做旧 walk，不声称其他敌人拥有独立动作。参考为 v9 `assets/enemies/charger.png`，已先实看：朝左奶白钻角、黄赭重甲、苔绿脊背、炭灰四足，三图保留同一身份与相机方向。每张一次首稿生成，无修订，无任何 PNG 后处理。完整提示与原始路径在 prompts.json，项目 PNG 本身就是原始生成字节。

## 接线

`assets/actions/charger/action_manifest.json` 的 actions 字典，路径均为 res://assets/actions/charger/。每图9帧保持原始顺序，固定418×320裁片、anchor [0.5, 0.9375]（足底参考 y=300）。图像来源1254×1254。为修正生成网格行距，每整行共用一次 y 平移；不逐帧按可见bbox重新居中，也不改变PNG。

charge：0–3前摇、4–6冲锋、7–8恢复；release_frame=4。实际 AI 的0.65秒前摇、0.6秒冲锋、0.8秒恢复及锁定方向/伤害由程序控制，原画不驱动额外攻击。hurt：中性→后仰→踉跄→复位；death：中性→跪落→伏地→终止，末帧不复活。无攻击轨迹、危险线、地面圈、速度拖尾或新武器。

三图首帧**均是中性站姿**。reference_height 分别183/174/199，是对应源图同一角色中性身体高度；death199不是取倒地压缩高度。各图生成占画布比例不同，运行须用统一旧walk世界站高 / 各源reference_height做每clip固定缩放，不能强行共享源像素height或逐帧归一，否则会尺寸跳变或抵消蹲伏。头身姿势自然变化并非严格逐像素骨骼锁定。

## 实看与验证边界

已逐图逐帧实看：身份/左向一致；charge明确屈膝、低姿四足奔跑、回立；hurt抬角后仰再稳定；death身体高度下降且最后3帧伏地停留。未见大面积环境光晕，轮廓有少量低alpha边缘抗锯齿/彩色细像素，不宣称严格无AA的原生低分辨率像素画。

帧脚底仍有自然或生成微差：charge约0–2源像素，hurt约0–3，death初次倒地约0–11（按最后接地统一行底）；保持固定锚点而不把每帧脚底强行移回。运行大小下的头身/接地一致性还需GUI查看，**没有实际窗口整合验收**。角色完整，没有剪掉身体或纳入邻格。

`python docs/art/charger/validate_assets.py` 读取图像（不编辑PNG），验证RGBA、27帧非空且字节不同、统一裁片边界、alpha>8有效实体边距>=12、透明像素比例，生成manifest与validation.json。阈值只是结构检测，不代替视觉无晕检查；不同哈希也不代表每帧有完全不同语义，末帧允许保持。
