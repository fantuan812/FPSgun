# v6 九帧像素风特效素材

2026-10-22，使用内置 image_gen 实际生成；原始生成 PNG 不经 Python 绘画、抠图或改色，运行通过 AtlasTexture 非破坏切片。Prompt 与生成来源见 prompts.json。运行使用 assets/vfx/vfx_manifest.json；6 张 1254×1254 RGBA，3×3 行优先，每格 418×418。PNG 为真正透明，预览器显示的黑色不是背景贴图。

## 动作与时序建议

| 动作 | 帧 1–3 | 帧 4–6 | 帧 7–9 | 建议 FPS / 持续 |
|---|---|---|---|---|
| muzzle_flash | 点火、向右喷射 | 分叉破碎 | 余烬收束 | 30 / 0.30 秒 |
| hit_spark | 接触火花到星芒 | 最大冲击、碎片外散 | 少量碎屑 | 30 / 0.30 秒 |
| explosion | 中心亮点膨胀 | 峰值、绿色烟团分离 | 烟团与最后余烬 | 18 / 0.50 秒 |
| chain_arc | 细线到分叉电弧 | 路径改变、脉冲衰减 | 断裂、端点余电 | 24 / 0.375 秒 |
| shield_impact | 局部短弧受击 | 短弧碎裂 | 碎片消退 | 24 / 0.375 秒 |
| dash_trail | 短线到拖尾 | 峰值与拖尾破碎 | 余迹消退 | 24 / 0.375 秒 |

最终播放参数以 data/vfx.json 为准。本表是美术节奏建议，不驱动伤害。单次播放，9 帧均非空，末帧结束清除实例；没有承诺末帧完全透明。攻击预警边界仍由精确游戏几何绘制，不能用此艺术贴图替代。

## 锚点与切片

所有帧共用全格画布，manifest 的 alpha_bbox 仅供检查，不能据此逐帧缩放或重新居中。枪口向右，锚点 (0.28,0.52)；冲刺向右、前沿约 (0.76,0.52)；链电基准端点 (0.14,0.54)→(0.87,0.54)，可映射两目标；其余居中。Nearest 采样、像素对齐，建议运行时小尺寸显示；禁止平滑滤波或每帧按包围盒缩放伪造动画。

## 实看与验收边界

已逐张查看最终六张图：有明确点火/扩张/碎裂/消退而非九个独立立绘；爆炸重新生成以修复首版贴边，保留真正径向形态；冲刺经一次生成修订缩小并改善对齐。护盾是局部短弧，不是全屏护罩。

如实限制：这是高分辨率像素风 AI 图，不声称是严格统一 32×32 像素网格；有轻微低 alpha 边缘与自然位置漂移，未逐像素人工修绘。链电端点表现为短电极端帽；运行需要映射到目标，不能把端帽理解成场景物件。固定锚点防止代码引入二次漂移，但不能证明原画绝对亚像素配准。帧 9 仍有余烬，生命周期清除负责最终消失。
