# Violet Spitter 专属动作 · v11

新增 `spitter_shoot`、`spitter_hurt`、`spitter_death`，各九帧、3×3行优先。旧walk原图未改。三张均内置image_gen首稿，未进行任何PNG后处理；项目文件为生成原始字节副本。提示词与来源路径见prompts.json，SHA256见manifest。

## 身份与动作

参考v10既有spitter：朝左三分之四、青绿前甲、紫色炮管/后罐、奶白口沿/趾端、黑灰管线与橙金机械关节、苔斑。保留机械四足身份。

shoot：0–3撑足蓄力，4炮管伸展释放姿势，5后坐，6–8回稳；没有烘焙弹体、火光、危险线或攻击轨迹。实际射击与伤害由AI驱动，warning .65秒映射0–3，shot同tick进入4，recover .7秒映射4–8。hurt：中性→炮口抬起/身体后仰→稳住→中性，.27秒。death：中性→屈膝→降身→伏地→停留，.72秒；末帧不复活、不消散。

## 裁片/尺度合同

源图1254×1254，统一418×320裁片，anchor=[.5,.9375]即接地y=300。每图每整行一组固定y裁片原点用于纠正生成行距；没有按每帧bbox自动居中、缩放，也未修改像素。三图首帧中性站姿reference_height依次213、222、252；运行时用旧walk世界中性站高除各clip reference_height，整clip固定scale。death参考的是站姿而非倒地高度。全部neutral frame0底部恰300；death frame0/1/2均300，无首帧浮空。

底部有效alpha>8实测：shoot [300,303,304,299,300,303,300,300,303]；hurt [300,300,295,295,297,300,300,300,300]；death [300,300,300,299,300,301,299,299,301]。最大5源像素接地微差保留并披露；不能称严格脚底逐像素锁定。shoot帧4较宽主要来自炮管伸展，身高只比中性增加4源像素，不应逐帧缩放“纠正”动作。

## 验证与限制

运行 `python docs/art/spitter/validate_assets.py`，只读取PNG、重建JSON。27帧非空且哈希互异；RGBA；alpha>8安全边距最小shoot16/hurt20/death19像素；不会裁到邻格实体。透明与低alpha占比、逐帧哈希、接地点见validation.json。逐图实看确认身份/左向、动作连续性、无大面积光晕；存在细轮廓抗锯齿及少量低alpha像素，不宣称完全二值alpha。

**这是高分辨率像素风参考感/卡通sprite，存在平滑轮廓、渐变、生成细节漂移，不是严格原生低分辨率pixel art。nearest过滤不改变这一事实。** 末帧可有细节跳变，哈希互异也不代表完全独立语义。正式原生像素化需统一管线设计。本批只做来源/结构/实看验收，GUI运行接线仍由程序与总验收负责，未声称实际窗口验收或已发布。
