# v37 art provenance

The plus-in-ring, broken-connector and linked-node forecast glyphs are original small code-native drawings in ui/forecast_glyph.gd, made from lines/circles. No generated raster, borrowed external art, SVG import, new texture atlas or new font is used. Text labels carry the same meaning independently of shape/color. Existing catalog item icons retain their earlier provenance and are not relabeled as new art.

These glyphs do not enlarge the catalog or generic image-resource count. Exact source/packed code and controlled native screenshots, not invented PNG fingerprint coverage, establish the delivered presentation. Native visual acceptance is a separate later gate.
