# v4 机制道具与联动

本轮新增 **8件独特机制道具**，保留原12件，共20件道具、4武器。八件均唯一（上限1），占一个普通道具种类槽；价格、稀有度和展示描述由 `data/catalog.json` 管理，事件行为由 `scripts/effects.gd` 定义。不是仅靠新增标签加伤。

## 四套改变事件行为的搭配

1. **CHARGED NETWORK：继电器+战利电池**。拾到能量球获得一次充能（最多3）；下一次实际连到其他目标的链电从2目标变为4目标并消耗1次。无目标不浪费充能。
2. **STICKY JET：冲刺树脂+脉冲靴**。冲刺仍有击退，树脂每次伤害同时施加0.6s减速，普通移动速度变成55%；已经承诺的冲锋速度不变，避免破坏预警轨迹。不是把敌人基础速度永久乘小。
3. **MIRROR THORNS：镜面护壳+荆棘冠**。护盾格挡也发起荆棘反击，和实际受伤反击共享1s冷却，不同分支不能同一次伤害双发。
4. **BLOOD MINES：血能阀+拾荒地雷**。地雷击杀每个目标恢复5HP，无低血限制；回复仍不能超过最大生命。

这些搭配的实际目标数、减速、格挡反击、击杀回复均有独立验证；不宣称完成真人通关率或经济平衡。

## 事件合同与反递归

- `Effects.process(event, context)` 返回命令，不递归调用自身，也不直接改敌人或玩家。main消费命令。
- event有 `kind/epoch/sequence/source/depth`。事件epoch必须匹配，sequence必须严格大于已提交序号，重复和旧上下文事件无效。
- 主武器hit只接受primary且depth=0；二次伤害统一标记chain/thorns/trail/mine，不能再次触发hit；kill_cell仅接受primary击杀。
- 唯一允许的二次击杀联动是mine来源触发BLOOD MINES回复，回复不造成伤害也不生成事件，因此没有闭环递归。
- 所有新效果是确定性规则，无概率掷骰；链电同距离以敌人ID打破平局。商店仍使用独立seed RNG；不是跨帧率完整战斗回放。
- 实际击杀来源保存在敌人上；多武器及近战不能再次给本tick已死目标改归因，从而把链电击杀伪装成主武器击杀。

## 状态生命周期

- **暂停/背包/升级**：效果、冷却、减速、地雷引信与储能冻结且保留；仅事件epoch改变，拒绝切界面前排队的旧事件。打开背包不会损失资源或充值盾。
- **波切换**：清地带、视觉缓存、链电储能与ICD；每波护盾重新可用。波末自动收取能量球只入经验/经济，不带储能跨波。
- **重开**：新build、新事件上下文，所有效果与shield_spent清空；无局外永久增益。
- **移除/出售**：派生属性重算；移除树脂/地雷立即移除其地带，失去减速配对会清已有减速，失去储能配对立即清charges，移除盾立即失效。已消耗盾不能出售再买刷回。
- **死亡/胜利**：清瞬时效果；后续不得伤害或触发奖励。Boss也是合法链电/地雷目标，仍遵守原Boss一次领奖和死亡胜利顺序。
